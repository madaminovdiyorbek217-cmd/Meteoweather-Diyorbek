# Погода Узбекистана

Сайт с погодой по 14 регионам Узбекистана. Фон страницы показывает реальную погоду выбранного региона: дождь, снег, гроза, туман, ясное небо, ночь со звёздами.

Создатель: Диёрбек Мадаминов, Telegram [@madaminovv712](https://t.me/madaminovv712)

## Возможности

- Выпадающий список регионов с анимацией, избранные регионы, кнопка «ближайший регион» по геопозиции
- Прогноз на 15 дней, по нажатию на день показывается погода этого дня
- Почасовой график температуры и осадков
- Качество воздуха (AQI, PM2.5, PM10, озон, NO₂)
- Предупреждения: жара, мороз, ветер, гроза, град, сильные осадки, снегопад, туман, УФ, грязный воздух
- Советы: что надеть, фаза Луны, осадки и заморозки для садоводов
- Карта Узбекистана с температурами по областям
- Языки: русский и узбекский (латиница)
- Единицы: °C/°F, м/с или км/ч, мм рт. ст. или гПа
- Светлая и тёмная тема
- Установка как приложения и работа без сети (последние данные сохраняются)

## Как открыть в Visual Studio Code

1. Распакуйте архив `uzbekistan-weather.zip`.
2. В VS Code выберите **File → Open Folder** и укажите папку `uzbekistan-weather`.
3. Установите расширение **Live Server** (VS Code сам предложит его при открытии папки).
4. Нажмите правой кнопкой на `index.html` и выберите **Open with Live Server**.

Сайт можно открыть и двойным щелчком по `index.html`. Для загрузки погоды нужен интернет. Установка как приложения и service worker работают только через Live Server или после размещения на хостинге (нужен адрес http://localhost или https://).

```
uzbekistan-weather/
├── index.html              разметка страницы
├── manifest.webmanifest    данные для установки как приложения
├── sw.js                   работа без сети
├── icons/                  иконки приложения
├── css/style.css           оформление, светлая и тёмная темы
└── js/
    ├── i18n.js             тексты на русском и узбекском, даты
    ├── common.js           настройки, регионы, единицы, иконки
    ├── sky.js              анимированный фон (canvas)
    ├── uzmap.js            контуры областей для карты
    ├── data.js             запросы к Open-Meteo, кэш, демо-данные
    ├── insights.js         предупреждения, одежда, Луна, советы фермерам
    ├── views.js            отрисовка блоков страницы
    └── app.js              события, меню, настройки, запуск
```

## Что где менять

- Список регионов и координаты: `js/common.js`, массив `REGIONS`.
- Тексты и переводы: `js/i18n.js`. Чтобы добавить язык, скопируйте блок `uz`, переведите и добавьте код в `LANGS`.
- Пороги предупреждений (жара, мороз, ветер): `js/insights.js`, функция `alertsFor`.
- Цвета неба для разных видов погоды: `js/sky.js`, объект `PAL`.
- Интервал обновления данных: `js/app.js`, последняя строка `setInterval(refresh, ...)`.
- Ссылка на Telegram: `index.html`, элемент `<a class="maker">`.

## Данные

Погода и качество воздуха берутся с бесплатного сервиса [Open-Meteo.com](https://open-meteo.com/) (ключ не нужен). Контуры областей из Natural Earth (общественное достояние).

Если сервиса нет в сети, сайт показывает последние сохранённые данные с пометкой времени. Если сохранённых данных нет, показываются демонстрационные данные с жёлтой плашкой.

Кнопки «Предпросмотр фона» внизу страницы позволяют посмотреть любую анимацию, не дожидаясь нужной погоды.
